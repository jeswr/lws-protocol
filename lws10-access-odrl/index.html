An ODRL profile for expressing LWS access requests and active grants, independent of their RDF serialization.

Personal implementation proposal for review. This document is not a Working Group decision. Profile identifiers in the LWS namespace are proposed additions.

This optional profile uses [[!ODRL-MODEL]] and [[!ODRL-VOCAB]]. Requirements apply to producers and processors claiming the profile and to servers activating grants under it. Examples are informative. Core LWS requirements remain applicable.
