This section defines the four core operations of Linked Web Storage (LWS) and their HTTP binding. For each operation, the description of inputs, behavior and possible responses is an informative, transport-independent model; the HTTP binding that follows it is normative and is what conformance (see [](#conformance)) is tested against. Responses include success indicators, resource representations (where applicable), and error conditions. Implementations MUST handle these operations atomically and consistently, meaning each operation either succeeds completely or fails without partial side effects. In case of errors, responses SHOULD provide enough detail for <a>agents</a> to understand the issue without leaking sensitive information.
